# HTML Practice

A collection of HTML practice exercises and sample projects developed as part of the Internet and Web Technologies (IWT) coursework.

## 📁 Repository Overview

This repository includes foundational HTML topics, semantic structures, form handling, multimedia embedding, and tables.

### Topics Covered & Files:
- **Headings & Text Formatting:**
  - `index.html` - Basic HTML structure and headings (`h1` through `h6`)
  - `bold.html` - Text formatting tags (`b`, `i`, `u`, `mark`, etc.)
  - `heyy.html` - HTML page demo

- **Lists & Tables:**
  - `list.html` - Ordered, unordered, and definition lists
  - `table.html` - HTML tables with headers, rows, and data cells

- **Forms & Inputs:**
  - `form.html`, `form2.html`, `formx.html` - Standard form inputs, buttons, radio buttons, checkboxes, and select dropdowns
  - `feedbackform.html` - Comprehensive feedback form implementation
  - `login.html` - User login form interface
  - `step.html` - Multi-step / progressive form elements

- **Multimedia & Embedding:**
  - `attachments.html` - Audio (`<audio>`), video (`<video>`), iframes, and embedded PDF documents
  - `fevicon.html` - Adding custom site favicons
  - `audio/` - Sample audio files
  - `video/` - Sample video files
  - `images/` - Image assets used across pages
  - `documents/` - PDF and document attachments

- **Semantic HTML & Page Layouts:**
  - `semented.html` - Semantic layout using `<header>`, `<nav>`, `<section>`, `<article>`, `<aside>`, and `<footer>`
  - `profile.html` - User profile page structure
  - `engineer.html` - Engineer showcase demo page
  - `viewpost.html` - Post viewing layout
